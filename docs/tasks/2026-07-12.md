## core_satellite 전략 정식화 — 슬롯모드 문자열을 독립 전략 클래스(SSOT)로 승격
- [x] 사용자 지시: obs_core가 쓰는 `core_satellite`가 지금은 MultiStrategyManager 하드코딩 슬롯모드라 독립 전략 스크립트가 아님. 이를 `CoreSatellite`(BaseStrategy 서브클래스) 정식 클래스로 만들어 구성(leveraged_regime 70% + strategy_c 30%)의 단일 출처로 삼고, strategy_factory에 등록. MultiStrategyManager는 하드코딩 대신 클래스의 선언된 구성을 읽어 슬롯을 생성. 기존 obs_core 슬롯·가중치·프리픽스·매매 동작 100% 보존(행동 무변경 리팩터링).
- 실측 검증: verify_harness 전체 통과(계약·카오스/롤백·컴파일274·NFC438·alembic·pytest 237 passed·프론트 tsc/lint·Playwright E2E 8/8). 신규 3케이스로 슬롯 동일성 강제(leveraged_regime 0.70/LR_ + strategy_c 0.30/SC_ = 기존과 완전 동일). get_strategy('core_satellite')→CoreSatellite·is_composite 확인. 서버 재기동 후 obs_core 라이브 사이클 오류 0건(시장 CLOSED라 진입은 다음 정규장 대기).
- 부수 발견·복구: 병렬 세션(안티그래비티 17종 작업)이 strategies 테이블을 94종으로 재생성하며 슬롯모드·복합·벤치마크 행 및 obs_core·obs_aggressive 계정을 삭제, obs_qqq_hold 전략을 leveraged_regime으로 변조. obs 3계정을 strategies 테이블(병렬 세션 소유) 무침해로 최소 복구(직접 재생성 + 표시용 내 전략 행 3종만 additive). 복구 후 obs_qqq_hold=benchmark_qqq_hold(QQQ 8)·obs_core=core_satellite·obs_aggressive=leveraged_regime_3x 정상.
