# 2026-07-14 Task Board

## SSE 실활성화 — view-trigger 제거 + 플래그 ON (구독 내부 refresh는 안전상 미채택)
- [/] 사용자 지시: 폴링→SSE 전환 마무리(실활성화). 당초 "SSE 구독=보는 중 → 구독 유지 중 주기 갱신(subscription-driven refresh)"을 SSE 스트림에 넣으려 했으나, 스트림 제너레이터 내부 asyncio.create_task+브로커 호출이 이 스택(Windows/asyncio/uvicorn)에서 스트림을 조기 종료시키는 불안정을 로컬 실서버 검증에서 확인 → 원인 불명확한 async 동작을 기본 on으로 main에 올리는 것은 부적절하다 판단, 미채택. 대신 (1) 폴링 기반 view-trigger(_should_trigger_refresh 등)와 단위테스트 제거, (2) 보는 유저 신선도는 기존 1분 스케줄러(admin_balance_cache_sync)+거래 이벤트 스냅샷을 기준으로 하고 SSE가 그 변경을 즉시 push, (3) 프론트 SSE_ENABLED 기본 opt-out(!= "false")로 ON. E2E는 결정성 위해 SSE off 고정. 과다 invalidation 방지: record_equity_snapshot은 유저 채널(balance/holdings)만, 관리자 랭킹은 1분 벌크 동기·이산 이벤트에서만 무효화.
- 실측 검증: verify_harness 전체 통과 목표 + 로컬 실서버 SSE 재검증(전송 전용 스트림 유지·bot 토글 push 도착 확인). 구독 내부 refresh 미채택으로 스트림 안정.
