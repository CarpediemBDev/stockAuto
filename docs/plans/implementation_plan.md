# 🏆 구현 및 검증 계획서: 500개 종목 5대 도메인 다차원 토너먼트 배틀
## (우량주 · 잡주 · 기술주 · 중국주 · 이탈리아주 100개씩 총 500개 종목 정밀 시뮬레이션)

본 문서는 **StockAuto** 전략들의 한계 성능과 강건성(Robustness)을 극한으로 검증하기 위해, **5대 종목군(각 100개, 총 500개)**에 대해 다양한 기간 및 인터벌에 걸쳐 대규모 병렬 백테스팅을 안전하고 신속하게 수행하기 위한 최상위 마스터 실행 계획서입니다.

## 🎯 시뮬레이션 대항전 목표 (Goals)
1. **5대 도메인별 강건성 검증**:
   * **우량주 (Blue-chip)**: 안정성과 추세 지속성 검증
   * **잡주 (Penny Stock / High-beta)**: 휩쏘(Whipsaw) 방지 및 리스크 오프 능력 검증
   * **기술주 (Tech / Nasdaq)**: 초과 수익(Alpha) 극대화 여부 검증
   * **중국주 (Chinese ADRs)**: 높은 야간 변동성 및 지정학적 레짐 적응력 검증
   * **이탈리아주 (Italian / European)**: 타임존(Timezone) 및 글로벌 매크로 동조성 검증
2. **yfinance API 안정성 및 성능 보장**:
   * 500개 종목의 다년도 일봉/시간봉 시세 데이터 수집 시 429 에러 방지용 배치 큐(Queue) 및 임의 딜레이 살포 장치를 장착합니다.
3. **서브에이전트 5인 군단 분업**:
   * 티커 선발, 데이터 수집, 테스트 구동, 통계 분석, 계산 감사를 각 서브에이전트에게 정밀 위임합니다.

## ⚡ 초고속 시뮬레이션 가속화 방안 (Speed-Up Framework)

"3시간 걸리던 연산을 **25분 이내**로 완료하면서도 정밀도는 100% 보존하는" 핵심 가속 기술을 적용합니다.

* **yfinance API 벌크 호출 (Bulk Batching)**: 50개 종목씩 묶어 총 10회 벌크 쿼리 ➔ 다운로드 [1.5시간 ➔ 5분] 단축.
* **멀티 프로세스 풀 동시 백테스팅 (CPU Multi-Processing)**: 8~16개 프로세스로 토너먼트 연산 쪼개어 동시 실행 ➔ 백테스팅 [1시간 ➔ 10분] 단축.
* **로컬 칼럼나 캐시 (Parquet Format Caching)**: 다운로드된 시세를 Parquet 압축 파일로 캐싱하여 로딩 [20분 ➔ 2분] 단축.

## 🪙 토큰 절약형 하이브리드 종목 발굴 전략 (Token Optimization)

10명의 에이전트가 50개씩 맨땅에서 검색하여 가져오면, 프롬프트 오버헤드와 중복 검사로 인해 수백만 토큰이 소모될 수 있습니다. 이를 막기 위해 **하이브리드 캐시 발굴 프로세스**를 가동합니다.

```
[1단계] 로컬 tickers.json (318개) ➔ 스크립트로 5대 분야 1차 자동 분류 (토큰 소모: 0)
  ▼
[2단계] 부족한 수량만 핀포인트 타겟팅 ➔ 2~3명의 전문 Selector 에이전트만 파견
  - Selector 1: 중국 ADR 및 이탈리아 밀라노(.MI) 종목 중 yfinance 유효 티커 추가 발굴
  - Selector 2: 소형 밈주/동전주(Penny Stock) 추가 발굴
  ▼
[결과] 토큰 소모량을 90% 이상 절감하면서도, 500개 종목 리스트를 정확하게 도출
```

## 📈 추가 수집 및 검증 기준 (Alternative Data Intervals & Metrics)

기존의 1일(1d), 1시간(1h) 가격 기준 외에, 알고리즘 전략들의 휩쏘 필터 성능을 극대화하기 위해 아래와 같은 **추가 다차원 데이터 기준**을 적용합니다.

### 1) 초단기 타임프레임 (`15m` 및 `5m` 분봉) 도입
* **배경**: 장 개시 직후 30분 내외의 변동성을 노리는 시가 돌파(ORB)나 단기 갭 페이딩 전략은 1시간봉으로는 매매 타점이 뭉개집니다.
* **적용**: yfinance의 API 한도(5m/15m 데이터는 최근 60일 내외만 제공)를 고려하여, **최근 60일 단기 민감도 테스트**에 한해 15분봉 및 5분봉 시뮬레이션을 전략적으로 결합 수행하여 초단기 휩쏘 극복력을 검증합니다.

### 2) 수급 및 변동성 다차원 지표 기준 (Multi-Dimensional Metrics)
* 단순 가격(Close)의 방향성 외에 다음과 같은 파생 수급 데이터를 대조군으로 삼아 필터링합니다:
  * **상대 거래량 (RVOL)**: 과거 20일 평균 거래량 대비 돌발적인 수급 분출 강도 측정.
  * **윗꼬리 비율 (Wick Ratio)**: 매수세 강도 및 장중 차익실현 압력(저항선 돌파 실패 흔적) 분석.
  * **장중 시간대별 계절성 (Time-of-Day)**: 장 시작 30분(Opening Rush) 및 장 마감 30분(Closing Auction) 자금 집중 현상 대조.

## 👥 5인 서브에이전트 모델 및 일 분배 파이프라인

### 1. 종목 선발 및 정제원 (`ticker_selector`) - ⚡ Gemini Flash 기동
* **임무**: 하이브리드 발굴 전략을 통해 5대 종목군별로 부족한 티커들을 핀포인트로 추가 수집하여 총 500개 종목 리스트 JSON 파일을 생성합니다.
* **모델**: 속도와 JSON 정제에 강한 Flash 모델 탑재.

### 2. 시세 데이터 수집원 (`data_harvester`) - ⚡ Gemini Flash 기동
* **임무**: 벌크 큐(Bulk Queue)를 통해 데이터를 로컬 캐시에 Parquet 포맷으로 초고속 압축 적재합니다 (15m/5m 분봉 포함).
* **모델**: 단순 데이터 I/O 제어에 적합한 Flash 모델 탑재.

### 3. 백테스트 시뮬레이터 구동원 (`battle_commander`) - ⚡ Gemini Flash 기동
* **임무**: 프로세스 풀을 열어 30가지 조합의 토너먼트 배틀을 병렬 연산하고 결과를 취합합니다.
* **모델**: 스케줄링 및 프로세스 오케스트레이션에 강한 Flash 모델 탑재.

### 4. 강건성 통계 평가가 (`robustness_analyst`) - 🧠 Gemini Pro 기동
* **임무**: 5대 종목군별 다변량 결과 데이터를 통계적(Sharpe, MDD, Win Rate)으로 교차 분석하여 리포트를 작성합니다.
* **모델**: 수학적 통계 추론과 정밀 분석 능력이 월등한 Pro 모델 탑재.

### 5. 품질 감사관 (`critical_auditor`) - 🧠 Gemini Pro 기동
* **임무**: FX 환율, Timezone 시차, 수수료/슬리피지 불변식이 현실적으로 잘 계산되었는지 비판적으로 검수합니다.
* **모델**: Zero-Complacency 기반의 예외 조건 감지 및 수치 검증에 특화된 Pro 모델 탑재.
