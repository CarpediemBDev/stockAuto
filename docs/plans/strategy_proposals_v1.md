## 💡 메인 에이전트(Antigravity)의 전략 평가 및 추천

> [!TIP]
> **추천전략 1순위: ConnorsRSI 초단기 극점 평균 회귀 전략 (에이전트 2 제안)**
> 
> *   **이유**: 우리 시스템은 이미 QQQ 레짐 스위칭을 통해 하락장에 공격성을 낮추고 현금화하는 훌륭한 방어 체계(RS 슬롯)를 가지고 있습니다. 하지만 하락장에 봇이 완전히 멈춰 있는 대신, **EP(에피소딕 피벗) 슬롯**에 **ConnorsRSI 극점 반등**을 심어둔다면, 시장 투매 폭락장에서 발생하는 우량주(예: NVDA, TSLA)의 초단기 기술적 과매도 극점 반등을 정확하게 낚아채서 안전하게 2~3%의 알파를 반복해서 챙길 수 있습니다. 구현 방식이 명확하고 기존 엔진의 `calculate_score` 구조에 깔끔하게 이식될 수 있습니다.

## 🚨 [중대 결함 보고] 기존 DarvasBox, HmaSwing 청산 역동작 버그

에이전트 1(c2d8654b-2bc6...)이 코드 리서치 중 발견한 **치명적인 버그**입니다.

### 1. 버그 현상
현재 `backend/app/strategies/darvas_box.py`와 `hma_swing.py` 파일의 `calculate_score(..., is_entry=False)` (보유 중 감시) 로직이 **정반대로 구현**되어 있습니다:

```python
# hma_swing.py (예시)
        else:
            # HMA 기울기가 우하향 전환 시 청산해야 함
            if hma_up == 0.0:
                return 100.0  # [버그] 우하향 전환되었는데 100점을 주어 청산을 방지함!
            return 30.0       # [버그] 우상향 정상 유지되는데 30점을 주어 강제 청산시킴!
```

### 2. 영향성
*   **유망한 종목은 진입하자마자 즉시 털어내고, 하락 전환하여 하락하는 위험 종목은 손절선에 닿기 전까지 청산 없이 홀딩**하는 심각한 역동작을 유발하고 있습니다.
*   이로 인해 백테스팅 아레나 및 라이브 거래 시 엄청난 수수료 누수 및 손실이 발생했을 가능성이 매우 높습니다.

### 3. 해결을 위한 대안 코드 설계
*   `is_entry == False` 일 때 리턴 스코어를 다음과 같이 정상적으로 교정해야 합니다:
```python
        else:
            if hma_up == 0.0:  # HMA 우하향 전환 시
                return 0.0     # 0점을 리턴하여 score < 40/50 붕괴 조건 만족 -> 청산 트리거
            return 100.0       # 우상향 유지 시 100점 리턴 -> 홀딩
```
